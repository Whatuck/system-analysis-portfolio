## Кейс 1: Тестовое задание на позицию Системного аналитика
**1. Анализ и доработка ТЗ**
Проанализировала отрывок технического задания на предмет логических противоречий, недочетов и неполных мест. 
*   Нашла 4 логических противоречия.
*   Выявила 12 неполных мест.
*   Сформировала список уточняющих вопросов к бизнесу.
*   Предоставила исправленную версию ТЗ с устраненными конфликтами.

**2. Проектирование API**
Разработала контракт REST API для экрана со списком партнеров (магазинов).
*   Описала структуру GET-запроса.
*   Спроектировала JSON-ответ, учитывающий разные типы доставки, а также ссылки на партнёрские ресурсы.

**3. Проектирование архитектуры PUSH-уведомлений**
Разработала верхнеуровневую архитектурную схему отправки PUSH-уведомлений, отражающую взаимодействие клиентского приложения, бэкенда и сторонних сервисов.
